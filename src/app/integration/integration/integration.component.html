Basic Rules

  • Power Rule: d/dx[x^n] = n*x^(n-1)
  • Product Rule: d/dx[uv] = u'v + uv'
  • Chain Rule: d/dx[f(g(x))] = f'(g(x)) * g'(x)

Trigonometric

  • d/dx[sin(x)] = cos(x)
  • d/dx[cos(x)] = -sin(x)
  • d/dx[tan(x)] = sec²(x)

Exponential & Logarithmic

  • d/dx[e^x] = e^x
  • d/dx[ln(x)] = 1/x
  • d/dx[a^x] = a^x * ln(a)
